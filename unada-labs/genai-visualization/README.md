# Generative AI tools for architecture and interiors

## What it was
This was the first thing I worked on at UNADA Labs: tools that use generative AI to help with architectural and interior design work.

- **Render generation**: turning a rough input into a realistic render
- **Moodboards**: generating visual moodboards from a design brief
- **Room staging**: putting furniture and decor into an empty room image

I built the frontends in React and TypeScript and connected them to the generative AI APIs, so designers could use these from a normal web interface instead of a script.

The code is part of UNADA's product, so it isn't included here.
