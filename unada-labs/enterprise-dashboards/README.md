# Dashboards for a large enterprise client

## What it was
I built interactive dashboards for a large enterprise client in real estate that turned raw project and sales data into KPIs and trends people could read at a glance.

## How I approached it
1. **Start from the questions.** Before building anything, I listed what the people using it actually needed to know every week. A dashboard that shows everything ends up showing nothing.
2. **Clean and shape the data.** Raw exports had inconsistent names, missing values and different date formats, so most of the time went into getting one clean table.
3. **Pick a few KPIs and define them exactly.** Every number had a written definition, so two people reading the same dashboard couldn't come away with different meanings.
4. **Build top-down.** Summary numbers first, then trends, then the detail for anyone who wants to drill in.

The data and dashboards belong to the client, so only this write-up is here.
